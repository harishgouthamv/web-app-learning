# Project Overview

A full-stack web application with an Angular frontend and a Node.js/Express backend connected to MongoDB.

## Architecture

```
web-app/
├── frontend/        # Angular application
├── backend/         # Node.js + Express REST API
└── CLAUDE.md
```

**Frontend:** Angular (standalone components), communicates with backend via HTTP  
**Backend:** Node.js + Express, Mongoose ODM  
**Database:** MongoDB Local

- TypeScript generics and decorators
- MongoDB aggregation pipelines
